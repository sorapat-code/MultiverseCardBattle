# UI Art Slots

The whole UI is generated by code (fantasy theme: wood, leather, gold). Any
slot below can be replaced with a real image later by placing a file under
`Assets/_Project/Resources/UI/` (import as **Sprite (2D and UI)**). No code
change is needed; a missing file falls back to the generated look.

| File name (no extension in code) | Used for |
|---|---|
| `bg_menu` | Background of Main Menu, Campaign, Collection, Deck Builder |
| `bg_battle` | Background of the battle screen |
| `logo` | Title logo on the Main Menu (replaces the title text) |
| `portrait_player` | Player Leader portrait in battle |
| `portrait_enemy` | Fallback enemy portrait |
| `portrait_<name>` | Portrait for a specific enemy, lowercase letters/digits only (e.g. `portrait_darkking` for "Dark King"); used in battle and on the Campaign list |
| `card_back` | Reserved for the card back |

Recommended sizes: backgrounds 1920x1080, logo about 1200x300 (transparent PNG),
portraits 256x256 (square, cropped to a circle by the game).

Music slots are documented in the music section: `Resources/Music/menu`,
`battle`, `bgm`.
